Game Simulator

Overview

Game Simulator is a Java-based simulation project that models the operation of an arcade environment.  
It allows managing customers, equipment, and various game types like Arcades, Cabinet games, Active games and Virtual Reality games, while also handling exceptions such as invalid IDs, insufficient balance, or age restrictions.

This project demonstrates use of OOP principles such as inheritance, polymorphism, encapsulation, and exception handling.


 Features
1) Customer Management - create and manage customers, including their IDs, ages, and balances.
2) Game Simulation - simulate playing arcade, cabinet, and virtual reality games.
3) Balance & Discounts - manage customer balances, apply discounts, and handle insufficient funds.
4) Exception Handling:
    Handles custom exceptions such as:
  - AgeLimitException – when a customer is too young for a game  
  - InsufficientBalanceException– when a customer doesn’t have enough balance  
  - InvalidCustomerException – when the customer’s data is invalid  
  - IncorrectIdException – when an incorrect or duplicate ID is used
5)Equipment Simulation - enum that stores equimpent types.
